1. 프로그램 소개

OverlayPic은 컴퓨터 화면 위에 원하는 디자인 시안, 그림 레퍼런스, 문서 등을 반투명하게 띄워두고, 클릭 통과(Click-Through) 기능을 통해 아래쪽 프로그램을 그대로 조작할 수 있는 초경량 Windows 유틸리티입니다.

  • 무설치 포터블: 단일 .exe 파일로 USB나 클라우드 어디서든 즉시 실행 가능
  • 픽셀 퍼펙트 검수: Figma/XD 시안을 브라우저 위에 1:1로 얹어놓고 1px 단위까지 오차 확인
  • 정밀 트레이싱: 클립스튜디오/포토샵 위에 포즈 사진을 띄워두고 따라 그리기
  • 단일 모니터 멀티태스킹: 듀얼 모니터 없이 영수증/PDF를 엑셀 위에 반투명하게 띄워두고 입력

2. 시작하기 (이미지 로드 3가지 방법)

OverlayPic을 실행하면 첫 화면에 드롭 영역이 나타납니다. 아래 세 가지 방법 중 가장 편한 방식으로 이미지를 올리세요:

  1. 드래그 & 드롭
    탐색기에서 이미지 파일(PNG, JPG, WebP, GIF, BMP)을 OverlayPic 창으로 마우스로 끌어다 놓습니다.
  2. 원클릭 붙여넣기 (Ctrl + V)
    웹 브라우저에서 우클릭 "이미지 복사"를 누르거나, 캡처 도구로 복사한 후 OverlayPic 창에서 Ctrl + V를 누르면 즉시 로드됩니다.
  3. 원터치 영역 드래그 캡처 (Ctrl + Alt + X)
    글로벌 단축키를 누르면 화면이 어두워지며 캡처 모드가 실행됩니다. 원하는 영역을 드래그하면 그 자리에 즉시 반투명 오버레이가 생성됩니다!

3. 🎯 1px 정밀 미세 정렬 모드 (v1.0.4.0 신규)

마우스 드래그만으로는 맞추기 어려운 1픽셀 단위의 정밀 위치/크기 오차를 맞출 수 있는 전용 정렬 모드입니다.
평소에는 방향키 입력을 전혀 가로채지 않으며, 상단 컨트롤 바의 🎯 버튼을 켰을 때만 안전하게 동작합니다.

상단 컨트롤 바: [⊞] [투명도: 100%]   [👆] [🎯] [✂] [⋯] [ℹ] [─] [✕]

⌨️ 키보드 방향키 넛지 조작 (방식 A)

단축키 기능
방향키 (↑, ↓, ←, →) 창 위치를 1px 단위로 미세 이동
Shift + 방향키 창 위치를 10px 단위로 빠른 이동
Ctrl + 방향키 가로/세로 창 크기를 1px씩 정밀 조절 (←/→: 가로, ↑/↓: 세로)
Ctrl + Shift + 방향키 창 크기를 10px씩 조절
Esc 미세 정렬 모드 해제 (프로그램이 종료되지 않고 모드만 안전하게 닫힘)

🖱️ 외부 독립 플로팅 조그 패드 & 마우스 휠 (방식 C)

🎯 버튼을 켜면 메인 창 외부 옆에 독립 플로팅 조그 패드 창(Fine Tuning Window)이 나타납니다:

  • 시야 100% 확보: 메인 창 내부를 전혀 가리지 않아, 창이 작아도 오버레이 이미지를 온전히 보면서 정렬할 수 있습니다.
  • 자유로운 드래그 이동: 상단 헤더를 마우스로 잡고 모니터 원하는 곳(듀얼 모니터 포함) 어디든 편하게 옮겨둘 수 있습니다.
  • D-Pad 버튼 (▲, ▼, ◀, ▶): 마우스로 클릭하여 1px씩 이동 (Shift 클릭 시 10px)
  • 스텝 버튼 (1px / 10px): 중앙 버튼 또는 상단 버튼 클릭으로 기본 이동 단위 토글
  • 크기 조절 (W-, W+ / H-, H+): 가로/세로 1px씩 클릭 조절
  • 실시간 수치 확인: 현재 창의 절대 좌표 (X, Y)와 크기 (W, H)가 실시간으로 표시됩니다.
  • 조그 창 위 마우스 휠: 조그 창 위에서 휠을 굴리면 Y축 1px 이동, Shift + 휠은 X축 1px 이동!
💡 안전 장치: 위치/크기 잠금(Ctrl+L) 중이거나 클릭 통과(Click-Through) 활성화 중에는 오작동 방지를 위해 미세 정렬 모드가 자동으로 비활성화됩니다.

4. 주요 기능 상세 안내

🔍 실시간 투명도 조절

창 위 어디서든 마우스 휠을 굴리거나 키보드의 +, - 키를 누르면 불투명도(0.05 ~ 1.0)를 부드럽게 실시간 조절할 수 있습니다. 상단 슬라이더로도 직접 조절 가능합니다.

👆 클릭 통과 (Click-Through) 모드

상단의 👆 아이콘을 누르거나 Ctrl + Shift + T를 누르면 마우스 클릭이 반투명 이미지를 그대로 뚫고 지나가 뒤쪽의 프로그램(피그마, 웹 브라우저, 캔버스 등)을 직접 조작할 수 있습니다.
해제할 때는 Esc를 누르면 즉시 일반 조작 모드로 복귀합니다.

📐 창 크기 조절 & ↻ 1:1 원본 복원

Ctrl + 마우스 휠을 굴리면 원본 가로세로 비율을 유지하면서 확대/축소됩니다.
크기를 바꾼 후 원본 100% 픽셀 크기로 돌아가려면 Ctrl + R을 누르세요.

💾 이미지 즉시 파일 저장 (Ctrl + S)

화면 캡처로 뜬 이미지나 클립보드로 붙여넣은 이미지를 별도의 그래픽 툴 없이 Ctrl + S로 PNG(투명도 보존), JPG, BMP 파일로 바로 저장할 수 있습니다.

🔒 위치 및 크기 잠금 (Ctrl + L)

정렬을 마친 후 작업 중 실수로 창이 밀리거나 크기가 틀어지지 않도록 원클릭 고정합니다.

🏁 체커보드 배경 지원 (Space)

배경이 투명한 PNG 아이콘이나 일러스트의 정확한 외곽선과 알파 채널을 확인할 때 체커보드 격자를 켜고 끌 수 있습니다.

5. 단축키 총정리 표 (Keyboard Shortcuts)

단축키 기능 설명
Ctrl + Alt + X ✂️ 화면 영역 드래그 캡처 (캡처한 자리에 즉시 오버레이 생성)
🎯 버튼 클릭 🎯 미세 정렬 모드 토글 (플로팅 조그 패드 표시 & 방향키 활성화)
방향키 (↑, ↓, ←, →) 🎯 위치 1px 미세 이동 (Shift+방향키: 10px 빠른 이동) *정렬 모드 시*
Ctrl + 방향키 🎯 가로/세로 1px 크기 조절 (Ctrl+Shift+방향키: 10px) *정렬 모드 시*
Ctrl + S 💾 현재 오버레이 이미지 파일로 저장 (PNG / JPG / BMP)
Ctrl + V 📋 클립보드 이미지 또는 이미지 파일 붙여넣기
Ctrl + O 📂 이미지 파일 열기 (.png, .jpg, .webp, .gif, .bmp 등)
마우스 휠 / +, - 불투명도(Opacity) 실시간 조절 (0.05 ~ 1.0)
Ctrl + 마우스 휠 창 크기 비율 유지 확대 / 축소
Ctrl + Shift + T / Ctrl + T 👆 클릭 통과(Click-Through) 모드 토글
Esc 👆 미세 정렬 모드 / 클릭 통과 해제 (일반 모드 시 프로그램 닫기)
Ctrl + L 🔒 위치 및 크기 고정 (Lock)
Ctrl + R ↻ 1:1 원본 해상도 크기로 리셋
Space 🏁 투명 PNG용 체커보드 배경 토글
Ctrl + M 창 최소화

6. 추천 활용 사례 (Use Cases)

🎨 1. 프론트엔드 개발자 & 웹 디자이너 (Pixel-Perfect 검수)

1. Figma 디자인 시안을 캡처(Ctrl+Alt+X)하여 브라우저 위에 띄웁니다.
2. 🎯 미세 정렬 모드를 켜고 방향키로 헤더 위치를 1px 단위까지 정확히 맞춥니다.
3. 투명도를 50%로 설정한 후 👆 클릭 통과를 켜고 실제 웹페이지를 스크롤/클릭하며 레이아웃 오차를 픽셀 단위로 검수합니다.

🖌️ 2. 웹툰 작가 & 일러스트레이터 (포즈 대고 그리기)

1. 참고할 인체 포즈나 구도 사진을 엽니다.
2. 클립스튜디오나 포토샵 캔버스 위에 띄우고 투명도를 30~40%로 맞춥니다.
3. 클릭 통과를 켠 후 아래 캔버스에서 펜으로 포즈 라인을 바로 대고 따라 그립니다.

📊 3. 문서 대조 및 영수증 입력

1. PDF 영수증이나 종이 서류 사진을 띄웁니다.
2. 엑셀(Excel) 창 위에 반투명하게 올려두고 클릭 통과 모드로 아래 엑셀 셀에 숫자를 바로 입력합니다.

7. 자주 묻는 질문 (FAQ)

Q. 클릭 통과 모드에서 마우스 클릭이 안 먹혀요!
A. 클릭 통과 모드는 마우스 클릭이 뒤쪽 프로그램으로 통과되도록 설계되었습니다. 해제하려면 키보드의 Esc 키 또는 Ctrl + Shift + T를 누르세요.

Q. 창이 마우스로 안 움직이고 크기도 안 변해요.
A. 위치/크기 잠금(Ctrl + L)이 켜져 있는지 확인하세요. 잠금을 풀면 정상 조작됩니다.

Q. 언어를 영어로 바꾸고 싶어요.
A. 상단 더보기(⋯) 메뉴를 클릭한 후 🌐 Language / 언어 전환을 선택하면 한국어와 English가 즉시 전환됩니다.
