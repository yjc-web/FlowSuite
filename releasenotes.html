🎯 1px 정밀 미세 정렬 모드 (Fine Tuning Mode) 신규 추가

픽셀 단위의 정확한 UI 검수(Pixel-Perfect Check)와 정밀 일러스트 트레이싱을 위해 마우스 드래그의 한계를 보완하는 1px 단위 미세 정렬 기능이 추가되었습니다.

단축키 / 컨트롤 동작 설명
🎯 버튼 클릭 미세 정렬 모드 토글 (플로팅 조그 패드 표시 & 방향키 활성화)
방향키 (↑, ↓, ←, →) 창 위치를 1px 미세 넛지 이동
Shift + 방향키 창 위치를 10px 빠른 이동
Ctrl + 방향키 가로/세로 창 크기를 1px 정밀 조절 (←/→: 가로, ↑/↓: 세로)
Ctrl + Shift + 방향키 가로/세로 창 크기를 10px 단위 조절
조그 패드 마우스 휠 조그 패드 위에서 마우스 휠 스크롤 시 Y축 1px 이동 (Shift+휠: X축 1px)
Esc 키 미세 정렬 모드만 우선 안전 해제 (창이 닫히지 않음)
✨ UX 및 인터랙션 개선
  • 독립 플로팅 조그 패드(FineTuningWindow): 모드 활성화 시 메인 창 내부 이미지를 가리지 않고 외부로 띄워지는 독립 툴 윈도우 제공 (자유로운 마우스 드래그 이동, D-Pad 버튼, 1px/10px 스텝, 크기 조절, 실시간 좌표 표시)
  • 오작동 방지 안전 장치: 평상시에는 방향키를 일체 가로채지 않으며, 위치/크기 잠금(Ctrl+L) 및 클릭 통과(Click-Through) 상태에서는 미세 정렬이 자동 차단됩니다.
  • 다국어 및 메뉴 동기화: 더보기(⋯) 메뉴에 미세 정렬 항목 추가 및 한국어/English 실시간 언어 전환 완벽 대응
